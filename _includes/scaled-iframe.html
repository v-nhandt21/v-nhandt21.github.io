{% comment %} Shows a page in an iframe at its desktop design width, scaled down to fit the column, so the whole layout is visible. Below `min_fit` px of column width it falls back to a normal responsive iframe (scaling would make the text unreadable on phones). Usage: {% include scaled-iframe.html src="/files/foo/" title="Foo" width=1200 height=900 bg="#07060f" %} {% endcomment -%}
